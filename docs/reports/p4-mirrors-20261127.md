### Algorithm

For a draw item, instances are partitioned by `basis.determinant() < 0`:

* **positive batch** — unchanged authored mesh/transforms;
* **negative batch** — rendered with `S = diag(-1, 1, 1)` folded into the mesh:
  `B' = B * S`, `M' = S * M`, so `B' * M' = B * M` and `det(B') > 0` (no second
  engine flip). The bake reverses triangle winding, negates `normal.x`, and
  negates `tangent.x` / `tangent.w` (handedness), keeping the authored surface
  materials as the same resources. It is cached by mesh + override.
* **fast path** — a single-surface `BaseMaterial3D` (CULL_BACK) uses a cloned
  `CULL_FRONT` material instead of a mesh copy. The shared source material is
  never mutated. A two-sided source needs no flip.
* **standalone** — a one-instance batch is a `MeshInstance3D`; Godot compensates
  the negative-determinant node natively, so it stays native by default
  (`mirror_mode=native`). `TAT2_MIRROR_SINGLE=baked` opts into the same bake.
  `TAT2_MIRROR_FAST=off` disables the cull-front fast path.

`MultiMeshInstance3D` has **no** per-surface override in Godot 4.7.2 (verified:
`has_method("set_surface_override_material") == false`), so the cull-front path
is single-surface only; multi-surface meshes always bake.

## GPU probe for the integrator

```bash
build/qa/mirror_probe.sh --run --tag=p4mirrors
# explicit form:
xvfb-run -a -s "-screen 0 1280x720x24" \
  tools/godot --path game --rendering-driver vulkan \
  --script "$PWD/build/qa/mirror_probe.gd" -- --run --tag=p4mirrors
```

Outputs `build/qa/mirror_probe/p4mirrors.png` and `.log` (gitignored). The
probe prints one `MIRROR_PROBE <name>=red|black` line per object and a
`MIRROR_PROBE RESULT` line:

* `control_ok=true` is mandatory (positive CULL_BACK red, positive CULL_FRONT
  black) — otherwise the readback is not measuring culling;
* `native_mm=compensated|not_compensated` is the engine verdict for a mirrored
  MultiMesh instance;
* `native_single=compensated|not_compensated` is the standalone verdict; if it
  is `not_compensated`, set `TAT2_MIRROR_SINGLE=baked` for the port;
* `baked_mm=ok`, `cull_front_mm=ok`, `single_baked=ok` are the port-side fixes.

The probe must run with one Godot at a time (the wrapper takes the shared flock
only for the Godot process).

## Risks / open items

* **Memory.** The baked variants are a second uncompressed copy of the mesh
  arrays: 31.1 MB estimated for the Guildhall set (104 variants); forcing
  `TAT2_MIRROR_SINGLE=baked` adds the 168 standalone meshes, measured at 61.97 MB
  / 223 variants. Godot may store less with the source compression flags. The
  caches are cleared at the start of every load, so no cross-map retention.
* **Multi-surface.** `MultiMeshInstance3D` has no per-surface override, so the
  `CULL_FRONT` clone is limited to single-surface meshes; multi-surface and
  `ShaderMaterial` meshes bake. The `CULL_DISABLED` fallback is single-surface
  only and counted (`mirrored_cull_disabled`).
* **Tangents.** `tangent.x` and `tangent.w` are both negated (the bitangent
  handedness flips under a reflection). The real 3-surface mesh check compares
  every sampled normal/tangent component; the source format flags round-trip
  through `add_surface_from_arrays`.
* **Standalone native / fast path are still probe-dependent.** The code follows
  Godot's documented negative-scale compensation and the MultiMesh has no
  documented per-instance flip, but neither is measured on a GPU here. The probe
  decides; the two env fallbacks exist (`TAT2_MIRROR_SINGLE=baked`,
  `TAT2_MIRROR_FAST=off`).
* **Headless MultiMesh readback.** `MultiMesh.get_instance_transform()` returns
  identity under the dummy renderer, so the headless test cannot inspect stored
  per-instance transforms. It verifies the partition helper, the loader
  counters, node tags, baked-mesh provenance and standalone transforms; the GPU
  probe is the visual proof.
* **GC overlays.** The 8 negative GC leaf/broken nodes stay native
  `MeshInstance3D` and are outside the draw census; `TAT2_MIRROR_SINGLE=baked`
  does not apply to them. Counted as `gc_native_neg` in the test.
* **Non-triangle / unreadable surfaces.** The bake returns null and the variant
  is counted as `mirrored_unbaked` (0 on this data set) with a bounded warning;
  it is not silently claimed as fixed.

## `MESH_RECON` / result fields

`MESH_RECON` keeps the old fields (`mirrored=` is still the placement-transform
census) and appends `mirrored_bases`, `mirrored_multimesh`, `mirrored_single`,
`mirrored_splits`, `mirrored_cull_front`, `mirrored_cull_disabled`,
`mirrored_mesh_bytes`, `mirrored_mesh_count`, `mirrored_unbaked`. The `result`
dictionary carries the same values; `mirrored_transform_bases` preserves the old
`mirrored_bases` value. `MIRROR_RECON ... ok=` and a `push_error` on mismatch
make the per-load identity loud.
