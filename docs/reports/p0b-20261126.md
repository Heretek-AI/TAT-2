This is the P0b evidence run at the merged P0b HEAD. It runs the complete P0a
28-gate set plus the P0b instruments (E2E `p2`, parity-only governance, the cream
RED proof, the capture dry-run/self-test/manifest validation and the KF27
reference calibration) in **one** command:

```bash
build/qa/run_p0b_gates.sh
```

Every Godot invocation takes `flock /tmp/opencode/tat2-godot.lock`; the runner
refuses to start when another process already holds the lock.
`build/qa/runtime_smoke.sh` and `build/qa/p0b_capture.sh` are invoked **without**
an outer flock because they take the lock themselves. The final line was
`P0B_GATES PASS head=dfa8c7e… gates=35 expected_gates=1` — 35 passing gates plus
the cream proof, which is expected to fail.

## Source state and preflight

The worktree's copied `game/.godot` import cache predated P0b's new global class
`ParityGovernance`, so the first compile of the merged tree reported **6 broken
scripts** (`game_data`, `game_state`, `level_loader`, `net_manager`,
`personal_quest`, `mission_prep_ui` — all `Identifier "ParityGovernance" not
declared`) and `test_parity_only.gd` reported `GameState autoload missing`. This
was a stale cache, not a code defect: `tools/godot --headless --path game
--import` registered the class (`global_script_class_cache.cfg` now contains
`ParityGovernance`) and the compile measured clean. `--import` writes only
gitignored `.godot/` state and local `.uid` sidecars; it changes no tracked file.
The measured run is the post-import run.

At the moment of the run the tree carried the new runner and its own output
directory as untracked files (this is the evidence commit) plus those local
`.uid` sidecars; `uncommitted_entries_at_start: 29` in `p0b-run.log`. No tracked
file was modified by the run except the refreshed capture dry-run/self-test
evidence.
