## What is measured

Everything below is a headless read of the real scene tree, shader parameters,
text and rects. It does **not** measure rendered pixels.

### UI3-05 — Light Gem

- `STEALTH_ORB_SHADER` sizes the lit cap from `lit_amount` (`ndc` terminator
  `1.0 - 2.0 * amount`) and places it from `sector_dir`/`sector_z`; the circular
  glazed-sphere mask/normals from W5D are kept.
- Direction mapping is pinned: light right → canvas `+X` (0°), light above →
  canvas `-Y` (-90°), light on the viewer's side → `+Z`.
- Applied state: amount 0 / 0.5 / 1.0 gives lit-area 0 / 0.5 / 1.0, monotonic;
  the shader material receives the amount and direction.
- The frame keeps the authored `BPUI_UniversalStealthBall.Image_177`
  ColorAndOpacity violet `(0.082283, 0.109462, 0.686685, 1.0)` in all states.
- `GEM_AUTHORED_SLICES = 21` records the authored `SizeZ` /
  `NumTexturesInArray`; the 21-slice texture payload is absent from the extract.

**HARD_LIMIT**: `T_stealthball_Array` (21 × 256×256, `PF_DXT5`) is not in
`extracted/assets`; the directional sphere is a **PORT_APPROX**. The sphere
colours are sampled from the reference frames (KF17 concealed crown `10,9,53`;
KF16 exposed `217,200,161`; KF25 `237,222,195`), not invented.

### UI3-01 — player card and compass

- Card binds an explicit save handle (`P5 Handle`) and falls back to the

  badge reads the save.
- Compass: 560×8 px rule, centre tick 13 px, heading above the rule; 42° still

  `1,2,4`, no count text drawn. The preserved `slot_count_lbls` array stays 4

## PORT_DECISION / residual

- **Hotbar counts**: the reference draws no ammo counts. The port keeps the
  `slot_count_lbls` text contract (and `∞` on slot 4) but hides the labels,
  because T1-14-B/T3-01 assert the infinity glyph. Labelled port decision.
- **`CRANK [LMB]`**: the centre ring prompt is the reference copy; the live
  interaction binding remains `secondary_action` (the bottom-right
  `[HOLD] CRANK [RMB]` hint is unchanged). This is presentational parity only.
- **Blur**: the pause backdrop reuses the briefing blur shader; the skip QA hook
  `TAT2_UI_NO_STAGE=1` is used by the probe so the 2,107-mesh prep stage is not
  built. No shipped path sets it.
- **Not verified**: GPU pixels for the gem, blur and line weights; a live
  reference comparison is still required before any row moves to PASS.
