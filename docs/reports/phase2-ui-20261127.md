**Why the selection is `derived-approx`, not authored.** The extracted
`BPUI_UniversalStealthBall` records `NumTexturesInArray = 21`,
`MI_StealthBallTextureArray` → `M_TextureArray` with `TexArray` + scalar
`Index` (default 8.0), and `SetStealthValue` writes one scalar. The native
`TATUnifiedStealthWidget` code that chooses the index is **not** in the dump,
so there is no authored index→direction table to copy. The producer measures
it from the pixels; `mapping.kind` records what the payload actually is. The
HUD reports `authored_array` only when all 21 slices bind, otherwise the
existing `PORT_APPROX` fallback stays.

**Mapping evidence in this lane:** the derivation is proven on synthetic caps
with known angles (≤ 1.5° error) by `tools/test_stealthball_array.py` (22/22).
The real-payload evidence is two printed lines the integrator must capture:

```
STEALTHBALL_ARRAY status=payload_present slices=21 mapping_kind=<area_ramp|directional> out=...
GEM_PAYLOAD present=true: layers=21 table=21 kind=<...> slice=<0..20> missing=[]
```

`build/qa/ui_pixel_stats.py` — measurements only by default; `--strict` turns
the documented thresholds into an exit code:

- **gem**: cream lit fraction, centroid → direction/angle, angle vs the sidecar
  state angle, violet ring thickness;
- **compass**: rule row/thickness/span and the heading ink above it;
- **prompt**: ink count, contrast (p98 vs median), clipping at the ROI edge;
- **pause**: world luma ratio (dim) and **relative** edge-energy ratio (blur),
  so a dim-only overlay is not mistaken for a blur; modal ink;
- **briefing**: line runs, last ink row, paper bottom margin, overflow;
- **text invariants**: every named text ROI — ink bbox, clipped edges,
  contrast; solid panel fills are not reported as clipped text.

Stdlib decoder with an ffmpeg fast path (the repo already depends on ffmpeg);
`tools/test_ui_pixel_stats.py` paints synthetic frames with known answers
(15/15) for every metric.

   **not compiled** here — see §4).

   new `res://…png` literal), so the target set / capped / offenders counts must
   stay **1567 / 796 / 1 / 0**; confirm, do not re-baseline.
7. `make gate-ratchet` after the audit log refresh if the logs are re-committed.

## 4. Blockers / not verified

- **No 21-slice decode in this lane.** The extractor needs the shipped game
  (Steam forbidden here) and the project targets `net10.0` (host SDK is 8).
  The C# was checked against the CUE4Parse **1.2.2.202611** metadata
  (`UTexture2DArray`, `TextureDecoder.DecodeTextureArray(UTexture2DArray,
  ETexturePlatform)`, `TextureEncoder.Encode(CTexture, ExportOptions, out
  string)`, `PlatformData.GetNumSlices()/SizeX/SizeY/PixelFormat/PackedData`,
  `FTexture2DMipMap.BulkData.Header.SizeOnDisk`). A first-build compile error
  can only be in `ExportTextureArray`.
- **No GPU capture.** The harness parses, starts, and reaches the shot loop
  headless; every pixel number is unverified until the Xvfb run. The camera
  poses are the p0b route numbers; the staged frames are labelled.
- **Gem geometry** uses the authored `ImageSize 144` relation (frame and array
  share the rect), but no frame has compared the rendered sphere to KF14/17/24/25
  yet.
- **The `PORT_APPROX` label** stays in this tree because the payload is absent;
  it flips only on a successful real bind (`gem_path()`), never on a claim.
- The producer's selection weights (`0.35` angle term) are a **port decision**,
  recorded in the JSON `derivation.selection`; the mapping itself is measured.
