3. **Why this task should be split into multiple milestones (not a single one-shot cycle)**:
   - The video is `225.64 s` (`~3m46s`) at `3840x2160`, `~30 fps` (`6,696` frames) with stereo audio (`§1.1`).

   - Doing full dense frame/audio inspection + image extraction + programmatic/visual annotation + subsystem cross-referencing + spot-check verification in a single pass risks context saturation, missed short-lived HUD/VFX/audio cues, or inconsistent image-to-timestamp citations. Splitting into focused milestones allows parallel/pipelined verification and clean acceptance gates.
