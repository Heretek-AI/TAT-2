## What this run proves

One command ran the complete AGENTS definition-of-done set plus the P0a
acceptance probes, **serially**, on the merged tree:

```bash
build/qa/run_p0a_gates.sh
```

Every Godot invocation takes `flock /tmp/opencode/tat2-godot.lock`; the runner
refuses to start when another process already holds the lock (the W10-A2
deadlock shape). `build/qa/runtime_smoke.sh` is invoked **without** an outer
flock because it takes the lock itself. The leak probe uses the correct path
`res://probe_leak.gd` with `TAT2_NO_DEN_PROBE=1`.

Each gate log under `docs/reports/logs/p0a/` carries its exact command line,
start time, full output, exit code and finish time. The runner stops on the
first unexpected non-zero exit; this run finished `P0A_GATES PASS ... gates=28`.
`docs/reports/logs/p0a/normalize.log` is the integrator's post-merge
`make normalize` log and is kept, not regenerated, by this lane.
